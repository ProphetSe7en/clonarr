Scoring Sandbox
Test how releases score against your profiles. Paste a release name or search Prowlarr, then see which Custom Formats match and the total score. Each release is sent to your selected instance to be parsed and scored, so the result always matches what that app would do. This needs a working connection to that app, and scoring a large batch makes one request per release, so it can take a while. Indexer flags (such as Internal or Freeleech) live on the indexer, not in the release name, so they can't be scored here.
